# Developer Portfolio

Portfolio site for Diogo Amaral, built with Vite + React + TypeScript.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Publish to GitHub Pages

1. Create a public repository named `developer-portfolio` under GitHub account `diiogo91`.
2. Copy this directory's contents to that repository. Commit the generated `package-lock.json` after running `npm install`.
3. Set the default branch to `main` and push it.
4. In **Settings → Pages**, choose **GitHub Actions** as the build/deployment source.
5. The included workflow builds and publishes the website after pushes to `main`.
6. Expected URL: `https://diiogo91.github.io/developer-portfolio/` (available only after successful deployment).

**Note:** If you rename the repository, update `base` in `vite.config.ts` accordingly.
